# G8 History MYS Review Lab

An interactive review page for the Grade 8 History mid-year exam (MYS), SISB Humanities.

It covers Unit 0 (Why and how do we study History?) and Unit 1 (Why and how are empires built?) in nine stages:

| Stage | Tab | Workbook pages |
|---|---|---|
| 0 | Key words | 2 |
| 1 | History ideas | 2 |
| 2 | Unit 1 facts | 3–4 |
| 3 | Describe (4) | 5 |
| 4 | Name or explain? | 6 |
| 5 | PEEL builder (6) | 7–8 |
| 6 | Message (7) | 9–10 |
| 7 | Reliability (7) | 11–12 |
| 8 | Compare (8) | 13–14 |

Students practise on the page, then write a similar task in the printed MYS Review Workbook.

## Notes

- The whole page is one file, `index.html`, with no build step. Turn on GitHub Pages (Settings → Pages → Deploy from a branch → `main`, `/ (root)`) to publish it.
- Progress (points and stage seals) is saved in each student's browser, so students should use the same device and browser each time.
- The page loads `sisb-tracker.js` if it sits beside `index.html`, and logs completed stages through it. Without that file the page works the same and logs nothing.
- The practice sources are deliberately not the exam's sources. Sources marked "adapted" are shortened and simplified. Both cartoons are originals from *Punch* (1892 and 1906) and are in the public domain.
